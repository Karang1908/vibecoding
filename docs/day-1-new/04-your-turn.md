# Your turn

<p class="beat">Everything so far was us. This bit is you.</p>

## Open the chat

++ctrl+l++ — or ++cmd+l++ on Mac.

A panel slides in. That's your intern.

!!! tip "Nothing happened?"
    Click the chat or :material-star-four-points: icon in the right sidebar.

## Type this

<div class="prompt-slab" markdown>
<button class="copy-btn" title="Copy to clipboard" onclick="const p = this.closest('.prompt-slab').cloneNode(true); p.querySelector('.copy-btn').remove(); navigator.clipboard.writeText(p.textContent.trim()); this.innerHTML = '<span class=\'copy-icon\'></span> COPIED!'; setTimeout(() => this.innerHTML = '<span class=\'copy-icon\'></span> COPY', 2000)"><span class="copy-icon"></span> COPY</button>

Build a single-page personal profile website in one HTML file.

Include my name in big text at the top, a short bio paragraph, three cards showing skills, and buttons linking to my socials.

Make it look modern and clean with a dark background, rounded corners, and a purple-to-blue gradient on the name. Make it work on mobile too.
</div>

Paste. Enter. **Watch.**

Text streams past. Files appear. Don't read it — you'll just stress yourself out.

See an **Accept** button? Click it.

## Look at what you made

Right-click `index.html` → **Open with Live Server**

No Live Server? Double-click the file on your Desktop.

<div class="vibe-check" markdown>
<div class="vc-title">You made a website</div>

By typing one paragraph. Ninety seconds ago.

Screenshot it. Send it to the group chat.
</div>

## "Mine looks different"

Yes. Everyone typed the same words and got a different site.

> The AI is guessing what you meant. 60 people, 60 guesses, 60 websites.

<p class="beat">Nobody did it wrong. There is no wrong here.</p>

## Now break it

Go back to the chat. Talk to it. Plain English:

```
make the background lighter
```
```
add a projects section at the bottom
```
```
make the cards animate on hover
```
```
change my name to [your name]
```

**Five minutes. Play. Break things.**

## What just happened

You didn't learn to code today.

<p class="beat">You learned you can ask for software and get software.</p>
