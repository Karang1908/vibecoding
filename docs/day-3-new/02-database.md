# Give It A Real Database: Supabase

Right now, when you finish a game of *Survive Uni*, your score is calculated in your browser's temporary memory.

Which means:
- If you refresh the page, your score disappears.
- If you open the game on your phone, your previous run isn't there.
- If your friend plays, you can't see each other's scores.

<p class="beat">That is not a database. That is a sticky note.</p>

---

Why do we need **Supabase**?

> **"Our application needs somewhere on the internet to store, retrieve, and share data between users forever."**

Forget the intimidating buzzwords. A database is essentially a super-fast spreadsheet that lives in the cloud and never loses anything. It has tables (like Excel tabs), columns (like fields), and rows (records).

Supabase gives us a real, industrial-grade **PostgreSQL** database that our Next.js app can talk to in milliseconds.

## 2. Prompting Is Not Magic: The Leaderboard Prompt

Remember Rule 9 of Vibe Coding: **Prompting is not magic; it's about providing context and constraints.**

Look at the difference:

<div class="versus" markdown>
<div class="vs-bad" markdown>
#### :material-close-circle: The Weak Prompt
*"Make me a leaderboard."*

**The disaster:**  
The AI doesn't know what table columns to make, assumes you have user authentication, invents its own schemas, and breaks your existing Report Card.
</div>
<div class="vs-good" markdown>
#### :material-check-circle: The Architect Prompt
*"Add a leaderboard to our existing app using Supabase. When the game ends, allow the player to enter their name and submit their score to a 'leaderboard' table. Display the top 10 scores on the Report Card. Keep the current game loop intact. First give me the SQL to create the table, then tell me which files you will modify."*
</div>
</div>

## 3. Set Up Your Supabase Project (3 Minutes)

<div class="step" data-step="1" markdown>
### Create Project
1. Go to **[supabase.com](https://supabase.com/)** and click **Start your project**.
2. Sign in with your GitHub account.
3. Click **New Project**, name it `survive-uni-db`, create a secure database password, and select your nearest region.
4. Click **Create new project** (it takes about 1-2 minutes to prepare).
</div>

<div class="step" data-step="2" markdown>
### Copy Your Credentials
Once created, go to **Project Settings** (gear icon) → **API**:
- Copy the **Project URL**
- Copy the **`anon` `public` key**

*(Keep these in a notepad tab—we will use them securely in step 5).*
</div>

## 4. Run The Database Table SQL

In Supabase, click **SQL Editor** in the left sidebar → **New query**.

Paste this SQL and click **Run**:

```sql
create table leaderboard (
  id bigint generated by default as identity primary key,
  player_name text not null,
  total_score int not null,
  survival_rank text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Enable public read and write for our workshop demo
alter table leaderboard enable row level security;

create policy "Allow anyone to read leaderboard"
on leaderboard for select
using (true);

create policy "Allow anyone to submit scores"
on leaderboard for insert
with check (true);
```

<div class="vibe-check" markdown>
<div class="vc-title">Verify in the Table Editor</div>

Click **Table Editor** in the left sidebar and select `leaderboard`.  
You will see your table columns ready and waiting. That is a real Postgres database running in the cloud!
</div>

## 5. Connect Your App to Supabase

Now let's ask our AI to connect the game to our new table using the architect prompt:

<div class="prompt-slab" markdown>

I want to connect 'Survive Uni' to my Supabase database so players can submit their high scores to a global leaderboard.

Please:
1. Install the official `@supabase/supabase-js` package if not already installed.
2. Create a helper file at `src/lib/supabase.ts` that initializes the Supabase client using `process.env.NEXT_PUBLIC_SUPABASE_URL` and `process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY`.
3. Update `src/app/page.tsx` on the Report Card screen:
   - Calculate total score as `money + time + sanity`.
   - Add a clean name input field with a 'Submit to Leaderboard' button.
   - When submitted, save `{ player_name, total_score, survival_rank }` into the `leaderboard` table.
   - Fetch and display the top 10 all-time scores in a styled leaderboard table directly below the Report Card.
4. Keep all existing game mechanics intact and don't hardcode any keys.
</div>

## 6. Test Your Global Leaderboard

1. Create a file named `.env.local` in your project root:
   ```bash
   NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
   ```
2. Restart your development server (`++ctrl+c++` then `npm run dev`).
3. Finish a game, enter your name (e.g. *"Campus Legend"*), and click **Submit to Leaderboard**.
4. Check Supabase's **Table Editor** tab in your browser. Refresh it.

<p class="beat">Your score is recorded in the cloud database!</p>
