# Show us what you built

Four days ago you'd never made a website.

<p class="beat">Let's see what happened since.</p>

## Volunteers

    Everyone's is. Half-finished and real beats perfect and imaginary.

## Today — the last 45 minutes

Your app works. But it lives on **your laptop** and nobody else can touch it.

<div class="versus" markdown>
<div class="vs-bad" markdown>
#### 📦 Right now

- Only on your machine
- Data dies if you clear the browser
- Can't send it to anyone
- Key sitting somewhere unsafe
</div>
<div class="vs-good" markdown>
#### 🌍 In 45 minutes

- Live on the internet
- Real database behind it
- A link anyone can open
- Keys done properly
</div>
</div>
